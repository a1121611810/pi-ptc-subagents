## What the round did not settle

- **Criterion 6's `thinkingLevel` half is vacuous.** `AgentConfigLike` and `parseAgentMarkdown`
  have no such field, so a definition cannot pin one and the criterion as written could never be
  satisfied. The code was not changed; the criterion was wrong. Recorded on #185.
- **The `ptc-mode` status key** for agent availability carried the now-misleading value when this
  round closed. #187 removed it (`5752500`), and the round over that removal found the removal
  itself was held by nothing until a status assertion was added — see the #187 ledger.
- Coverage numbers were not consulted: every threshold in `vitest.config.ts` is `0`, so a coverage
  figure cannot fail anything and is not evidence of anything either.
