## What this round is actually about

S-01 is the fourth time in two rounds that a **correct citation carried a wrong verb**. The
previous round's ledger named this class; this round added another instance while fixing the
last one. The pattern: a measurement establishes X ("typecheck is clean on 0.87.1"), and the
prose written beside it claims X+ ("it passes every step"). Nothing checks the difference,
because the gate runs the measurement, not the sentence.

S-04 is the sharper one. The floor leg of `compat:pi` is the only place the migration's value is
observable, and it is not in the default gate — so the default gate could not have caught a
regression in #192's actual deliverable. It can now.
