(Standards, Spec), each in a read-only session against the commit.

modes that matter for a deletion are not the ones an addition has, and both axes went looking for
them: a comment elsewhere still asserting the removed thing exists, a record describing another
ticket's work, and above all **whether anything still holds the absence**.

## What the axes cleared with evidence

- **Audit 1 (call-point completeness).** An untruncated enumeration found the surviving registry
  readers in exactly two files — `src/runtime/dispatch.ts` (the resolver and the two refusal
  renderers) and `src/tools/subagent.ts` (the roster in the tool description). **`src/index.ts`
  appears zero times**, so acceptance criterion 5 holds: the production diff is one file and every
  surviving reader lives in a file the diff never touched. CodeGraph agrees on the chain.
- **Audit 2 (oracle).** F1–F4 patterns clean, and the meta-discipline fixture is green over the new
  bodies. Two counterfactuals were run in throwaway copies rather than argued: restoring the removed
  block reddens the new absence test (the notice half and, after S1, the status half), and blanking
  the status text reddens the migrated assertion.
- **Nothing dangling.** Nine deleted tests, all of whose subject was the removed warning; the one
  assertion from them that was about something else (the status line's content) migrated and keeps
  its counterfactual. No comment, doc, or test elsewhere still references the notice, the marker, or
  the two deleted files.

## What the round did not verify

- `tests/tool-visibility.test.ts` needs a built `dist/` and a provider, so the Spec axis did not run
  it; the workspace run and `verify:dist` cover it instead.
- The side effect the Spec axis named and neither axis treats as a defect: the **session-level
  surfacing** of an unreadable agents directory is gone with the notice. The `console.warn` inside
  `listRegisteredAgents` is untouched and still pinned by `dispatch-helpers`, so no warning path was
  lost — only the startup echo of it.
