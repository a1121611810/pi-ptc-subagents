## 0. 结论速查

**一句话**：本仓是 Node 库 / pi 扩展，**没有 React、没有 JSX、没有 DOM、没有浏览器**——这一条事实一次性判掉 5 个 oxlint 插件（react / react-perf / jsx-a11y / nextjs / vue，实测各 0 条诊断）和 vitest 的大部分「集成」面（browser / jsdom / happy-dom / webdriver / axe）。真正值得动的是三处：

3. **oxfmt 的配置面（29 个顶层选项）在本仓几乎全是噪声**：`sortImports` 会改 136 个文件、`jsdoc` 会改 168 个、`proseWrap: "always"` 会改 173 个、`printWidth` 改 80/120 分别改 204/170 个。**唯一有实义的是 `ignorePatterns`**——而本仓已经用了它。

### 1.3 「假阳性」是怎么判的

一条诊断满足**任一**条件即判为**假阳性**：

- **(a) 它对本仓代码的陈述是错的**——解析错了、认错了符号、把一个不是那东西的东西当成了那东西；
- **(b) 它成立的前提在本仓不存在**——它假设了一套本仓不是的 API（本仓用 vitest 而非 jest）、或假设了一类本仓不是的目标（本仓是 Node 库而不是浏览器包）。

明确**不算**假阳性的一类，单列为**「约定类」**：陈述本身准确、只是与本仓约定不同的风格意见。这类诊断**既不是缺陷、也不是假阳性**，本笔记不与假阳性混算，只在理由里点名。

判定方法：每条规则先取消息直方图，再回到源码行逐条读（`tests/tool-visibility.test.ts:576` 这类行号 + 原文），凡是要下判断的规则都读过源文件，不是只看消息文本。

### 1.4 测量范围与隔离方法（这一节决定所有数字可比）

- **范围 = 本仓 `oxlint` 现在实际 lint 的 174 个文件**。用 `oxlint --debug=files` 比对确认：仓库 config 跑出来的文件清单与隔离 config 跑出来的**逐行相同**。
- **隔离 = 每个插件一份临时 config**，`plugins: ["<该插件>"]` + 全部 7 个 category 全开 + `env.builtin` + `options.typeAware: true`（与仓库一致）+ 与仓库相同的 `ignorePatterns`。
- ⚠️ **踩到的坑（方法价值在此）**：oxlint 与 oxfmt 的 `ignorePatterns` 都是 **gitignore 风格、相对于「配置文件所在目录」** 解析的，配置文件放在别处时**匹配不到仓库里的目录**，且「配置文件所在目录之外的文件无法被匹配」。第一版把临时 config 放在 `.scratch-out/` 下，lint 文件数变成 207（多出 `docs/prototypes`、`packages/website`、`docs/research` 33 个文件），react/vue 计数会被这批文件污染。**临时 config 必须写在仓库根目录。**
- **诊断归属**用 oxlint JSON 里的 `code` 字段前缀（`jest(valid-expect)` / `import(no-cycle)` / `eslint(no-undef)`）切分，与插件 scope 一一对应。
- **「诊断数」的口径 = 该插件在全部 category 下的诊断总数**（即「如果整包开这个插件，它会说多少句」）；「本仓现状」另列，两者不混。
- `vitest` 插件一行**沿用票面既测结论**（101 条 = 93 `valid-expect` + 8 `expect-expect`，全部判为假阳性），**本轮没有重测**。

### 6.1 oxfmt 小结

- **29 个顶层选项里，本仓真正用上的只有 `ignorePatterns`（已在用）**；默认开着的 `sortPackageJson` 是空操作；默认关着的 `sortImports` / `sortTailwindcss` / `jsdoc` 三个，每一个都会改动 136 / 0 / 168 个文件且换不到任何已记录的缺陷。
- **oxfmt 唯一「没被用上但有用」的一格是 `overrides`**——但它解决的是「同一配置下要分叉」，而本仓现在是「整个子目录排除」，两者不能互相替代。
- 配置发现是**逐文件向上找、最近的赢**——这意味着在 `packages/website/` 下放一个 `.oxfmtrc.json` 就会让那一段脱离根配置；**本仓现在没有这个文件，所以 393 个文件里的每一个都吃的是根配置**。
