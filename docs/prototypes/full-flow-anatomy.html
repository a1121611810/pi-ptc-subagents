  · cancel-queued：当前还是 queued 才 canceled；不是 → 原样返回、不改、不写、不报错（竞态常态）
  · attach-report / attach-output：终态上的迟到写入 → 静默丢弃（不覆盖终态记录）
  · #move：出队转 running 那一刻盖 startedAt；进终态盖 finishedAt（durationMs 只量孩子跑起来之后）
        │
谁触发哪条边：
  transition running   = 泵启动前（⑨）
  cancel-queued        = stop(queued) / 等待者 abort / withdrawn / shutdown 抽干 / restore reconcile
  resolve-exit         = 泵 close（stopping→canceled 是 stop 的收尸）
  reconcile-lost       = 重启恢复发现 owner 已死（⑮）
