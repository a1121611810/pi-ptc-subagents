需求：给 `src/inventory/` 下的 24 个工具模块各出一张「接口卡」，并出一份汇总表。

背景：

- `src/inventory/` 下有 24 个工具模块（不含 `__init__.py`），它们互不相干。
- `CLAUDE.md` 是本项目的开发规范，动代码前先读。
- `tests/test_smoke.py` 已经存在，导入每个模块——不要动 `tests/`，也不要动 `src/inventory/` 下的任何代码。

要交付的东西：

## 1. 每个模块一张接口卡

`docs/pkgcards/<模块名>.md`，`<模块名>` 就是模块文件名去掉 `.py`（例如 `totals_01`）——24 个模块各一张，一个都不能少。

每张卡的内容按下面这个格式写（字段名照抄，不要自创）：

```
# <模块名>

- 模块名：<模块名>
- 代码行数：<N>
- 职责：<一句话说明这个模块负责什么，要具体到这个模块的真实职责>

| 函数名 | 参数名 |
| --- | --- |
| <函数名> | <参数名1>, <参数名2> |
```

规则：

- 「代码行数」= 该模块 `.py` 文件里**去掉空行**、**再去掉整行注释**（去掉行首空白后以 `#` 开头的那几行）之后**剩下的行数**；docstring 的行算代码行。
- 表格里列出该模块的**全部公开函数**（模块顶层、不以 `_` 开头的 `def`；类不是函数，不列）。「参数名」按函数定义里的顺序，用 `, ` 分隔。
- 「职责」写一句话，不要写「本模块提供工具函数」这种放之四海皆准的话。

## 2. 一份汇总表

`docs/pkgcards/index.md`，每个模块一行，格式：

```
| 模块名 | 职责 | 代码行数 |
| --- | --- | --- |
| <模块名> | <一句话职责> | <N> |
```

- 一行一个模块，**按模块名字典序排列**
- 表格下面再写一行合计：`| **合计** |  | <24 个模块代码行数之和> |`
- 汇总表必须覆盖 24 个模块，一个不漏

## 3. 跑测试

`uv run pytest` 必须全绿（`tests/test_smoke.py` 一条都不能挂）。

## 约束（来自 CLAUDE.md）

- Python 3.11+ 原生类型标注
- 不新增第三方依赖，不改 `pyproject.toml`
- 只新增 `docs/pkgcards/` 下的文件，不要动 `tests/`、不要动 `src/`

做完后给一份简短说明：出了几张卡、汇总表多少行、测试运行结果。
